# Security

Report vulnerabilities privately through [GitHub's Report a vulnerability](https://github.com/vjk7989/h0x-ADE-app/security/advisories/new). Don't post exploit details in a public issue.

Include the HyperOx version, OS, what you found, steps to reproduce it, and the impact. A small proof of concept helps. Remove secrets and personal data from logs.

Only the latest release is supported.

For how HyperOx handles trusted mods and updates, see [security and privacy](docs/security.md).
